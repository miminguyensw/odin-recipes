# Odin Recipes

A small recipe website built as part of The Odin Project's Foundations course.

## What I built
- A home page that links to three recipe pages
- Recipe pages with an image, a description, an ingredient list and step-by-step instructions

## What I learned
- Setting up an SSH key and connecting my laptop to GitHub
- The Git workflow: cloning a repo, then status, add, commit and push after each step
- The basic structure of an HTML page (boilerplate with head and body)
- How relative paths work in links, like `recipes/bun-cha.html` and `../index.html`, which works the same way as `cd` in the terminal
- Adding images with `src` and `alt`, and the difference between unordered and ordered lists
- Using terminal commands
